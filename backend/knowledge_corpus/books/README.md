# Book System — Livres métier d'Artizen

> **Version** 1.0 — **Status** Validated — **Owner** Éditorial / Contenu métier — **Last Update** 2026-08-02
> **Depends On:** [../taxonomy/README.md](../taxonomy/README.md), [../factory/README.md](../factory/README.md) — **Used By:** responsables de Livre, lecteurs, IA

## Objective
Définir le **système officiel des Livres** : l'organisation à grande échelle du patrimoine métier,
capable d'accueillir **plusieurs centaines de milliers** de Knowledge Cards **sans réorganisation**.
**Ce n'est pas du contenu** ; aucun Livre n'est rempli ici.

## Principe fondateur (conformité)
Un **Livre = une curation par références** (une **projection**) sur le Corpus, **alignée sur la
taxonomie gelée** : **Collection = famille (6)** › **Livre = activité (62)**. Un Livre **ne contient
aucune connaissance en propre** : il **référence** des cartes/kits/phrases/diagnostics… **jamais de
duplication** (Loi 1). Il n'invente **aucune** organisation concurrente de la taxonomie.
