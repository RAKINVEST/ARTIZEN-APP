## Points à vérifier
- [ ] **Tronçonneuse** : EPI anti-coupure, chaîne/frein, technique anti-rebond. `[A]`
- [ ] **Débroussailleuse/broyeur** : écran, périmètre, protection auditive. `[A]`
- [ ] **Phytosanitaire** : Certiphyto, ZNT, EPI, stockage ; alternatives privilégiées. `[A]`
- [ ] **Réseaux** repérés avant terrassement léger. `[A]`
- [ ] **Biodiversité** : périodes de taille (nidification), espèces protégées. `[A]`
- [ ] **Manutention** ; **hauteur** (élagage = spécialisé) ; **amiante** = certifié. `[A]`
