## Points à vérifier
- [ ] **Fixation murale anti-basculement** des meubles hauts (danger enfants). `[A]`
- [ ] **Ancrages adaptés au support** (plaque de plâtre ≠ maçonnerie) ; charge. `[A]`
- [ ] **Manutention** des éléments volumineux : binôme/levage. `[A]`
- [ ] **Découpes / poussières de bois** : aspiration/masque ; **bruit**. `[A]`
- [ ] **Repérage réseaux** avant percement ; **éclairage/élec** = interface. `[A]`
- [ ] **Amiante** (rénovation) : diagnostic ; retrait = **certifié** (jamais ici) ; **arrêt** si danger. `[A]`
