# Tool Types — Outillage

> **Version** 1.0 — **Status** Validated (éditorial) — **Owner** Éditorial / Contenu métier — **Last Update** 2026-08-02
> **Depends On:** [TAXONOMY.md](TAXONOMY.md) — **Used By:** cards, kits

## Objective
Classer l'**outillage** d'une carte. Axe `outil:` par **catégorie** (l'outil précis reste du contenu
éditorial). Vocabulaire contrôlé, extensible.

## Catégories officielles (`outil:`)
| Slug | Exemples de contenu |
|---|---|
| `manuel` | clés, pinces, tournevis, niveau |
| `electroportatif` | perceuse, meuleuse, visseuse |
| `mesure` | mètre, télémètre, multimètre |
| `controle` | manomètre, caméra d'inspection, testeur |
| `securite` | EPI, harnais, extincteur |
| `soudure` | poste à souder, chalumeau, fer |
| `coupe` | coupe-tube, scie, cisaille |
| `percage` | perforateur, forets, carottier |
| `levage` | palan, sangles, échafaudage |
| `nettoyage` | furet, aspirateur, karcher |
| `raccordement` | sertisseuse, dudgeonnière |

## Règles
- `outil:` classe par **catégorie** ; le détail (marque/modèle) est du contenu de carte.
- La **sécurité** (EPI) est aussi rappelée dans le champ Sécurité de la carte.
- Extensible ; synonymes → [ALIASES.md](ALIASES.md).

## Décompte
**11 catégories d'outillage** (extensible).
