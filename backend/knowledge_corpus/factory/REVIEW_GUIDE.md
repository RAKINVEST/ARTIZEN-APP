# Review Guide — Guide du relecteur

> **Version** 1.0 — **Status** Validated — **Owner** Éditorial / Contenu métier — **Last Update** 2026-08-02
> **Depends On:** [QUALITY_CHECKLIST.md](QUALITY_CHECKLIST.md), [../QUALITY_RULES.md](../QUALITY_RULES.md) — **Used By:** relecteurs

## Objective
Cadrer la **relecture métier** : détecter ce que l'auteur/IA ne voit pas, avant la validation.

## Grille de relecture
| Axe | Contrôle |
|---|---|
| **Exactitude métier** | le geste est correct, sûr, réaliste ; temps/difficulté crédibles |
| **Cohérence** | pas de contradiction interne ; étapes ↔ outils ↔ matériaux concordent |
| **Taxonomie** | activité/famille/tags conformes ([../taxonomy/](../taxonomy/README.md)) ; une seule branche principale |
| **Relations** | kit/phrases/diagnostics/normes pertinents et présents ([../RELATIONSHIP_RULES.md](../RELATIONSHIP_RULES.md)) |
| **Sources & confiance** | chaque info sourcée ; niveau A/B/C/D cohérent ([CONFIDENCE_MODEL.md](CONFIDENCE_MODEL.md)) |
| **Illustrations** | conformes, utiles, sans donnée personnelle |
| **Doublon** | pas d'équivalent existant (sinon référence/variante — [CHANGE_POLICY.md](CHANGE_POLICY.md)) |
| **Langage** | artisan, test des 5 secondes |

## Décisions du relecteur
- **Conforme** → transmet à la validation.
- **Corrections** → renvoie à la rédaction avec remarques précises (jamais un rejet vague).
- Le relecteur **ne valide pas** (séparation des rôles) ; il prépare la validation.

## Rôle de l'IA côté relecture
Pré-relecture automatique : cohérence, doublons, complétude, conformité taxonomie. **Signale**, ne
tranche pas ; la relecture métier reste humaine.
