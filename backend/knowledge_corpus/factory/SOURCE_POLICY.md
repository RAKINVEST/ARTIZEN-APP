# Source Policy — Politique de sources

> **Version** 1.0 — **Status** Validated — **Owner** Éditorial / Contenu métier — **Last Update** 2026-08-02
> **Depends On:** [CONFIDENCE_MODEL.md](CONFIDENCE_MODEL.md) — **Used By:** auteurs, relecteurs

## Objective
Définir ce qui constitue une **source valable** et comment la citer. Règle d'or : **aucune information
normative ou de sécurité sans source**.

## Sources recevables (par niveau)
| Niveau | Sources | Citation attendue |
|---|---|---|
| A | DTU, normes NF/EN, textes réglementaires, doc fabricant officielle | référence précise (n° DTU/norme, éditeur, date/version) |
| B | notice technique, formation constructeur, fiche produit | titre + éditeur + version |
| C | retour terrain validé, expert identifié, entreprise pilote | auteur/validateur + contexte |
| D | hypothèse | mention explicite « à confirmer » + piste de vérification |

## Règles
- **Chaque information clé** est **sourçable** ; sécurité/normes = niveau **A/B** obligatoire.
- **Jamais** de norme citée de mémoire/approximée : référence exacte ou rien.
- Une source **périmée** (norme abrogée, notice obsolète) déclenche une **révision** ([CHANGE_POLICY.md](CHANGE_POLICY.md), [DEPRECATION_POLICY.md](DEPRECATION_POLICY.md)).
- Les sources sont **conservées** dans la carte (traçabilité, append-only).
- Respect du droit : citer, **ne pas recopier** un contenu protégé ; reformuler + référencer.

## Interdits
Norme inventée/approximée · affirmation de sécurité non sourcée · copie de contenu protégé · source non vérifiable.
