## Cadrage
- **Objectif** : comprendre le rôle du spécialiste : **diagnostiquer** les attaques biologiques et **prévenir/traiter** le bois — distinct du charpentier. `[C]`
- **Résumé** : le traitement de charpente vise à **protéger le bois** contre les attaques biologiques (**insectes xylophages**, **champignons lignivores**, **termites**) : diagnostic, prévention, surveillance et, si besoin, **traitements préventifs/curatifs** (présentation uniquement, application **réglementée** — Certibiocide) ; la **structure** et son remplacement relèvent du **Charpentier**, l'**humidité** (cause racine) du **Couvreur/Maçon**, le **diagnostic** réglementaire du **Diagnostiqueur** — métiers distincts. `[C]` ⟦périmètre selon prestation à confirmer⟧

## Réalisation
- **Étapes** *(compréhension / diagnostic / organisation — aucun protocole d'application de biocides décrit)* :
  1. **Diagnostiquer** les attaques biologiques. `[C]` → [diagnostiquer-attaques-biologiques](diagnostiquer-attaques-biologiques.md)
  2. Structure / remplacement = **Charpentier** (frontière). `[C]` → [diagnostiquer-attaque-bois](../../../professions/charpente/cards/diagnostiquer-attaque-bois.md)
  3. **Humidité** = cause racine (Couvreur/Maçon). `[A]` → [comprendre-role-humidite](comprendre-role-humidite.md)
  4. Traitements = **présentation** (application réglementée). `[C]` → [comprendre-traitements-preventifs-curatifs](comprendre-traitements-preventifs-curatifs.md)
- **Points critiques** : diagnostic/prévention prioritaires ; **humidité = cause** ; traitements = **présentation** (Certibiocide) ; frontières (charpentier/couvreur/maçon/diagnostiqueur).
- **Sécurité** : biocides (réservé) ; hauteur/combles ; structure affaiblie. **Produits biocides** : les traitements du bois utilisent des **produits dangereux** (toxiques/irritants, parfois inflammables) — leur **application professionnelle** est **réglementée** (**Certibiocide**, Règlement Biocides), sous EPI, ventilation et protection des occupants ; **ce Livre ne décrit aucun protocole d'application** (présentation uniquement). **Travail en hauteur / combles** : accès difficile, planchers fragiles, chutes. **Poussières de bois** (cancérogènes, débris d'attaque) → aspiration/masque. **Électricité** en combles : prudence (câblage). **Amiante** (anciens traitements, matériaux en combles/calorifuge) : diagnostic ; retrait réservé à une **entreprise certifiée** (**jamais ici**). **Protection des occupants / animaux** pendant traitement (relais professionnel). **Structure affaiblie** par l'attaque = **risque d'effondrement** → **arrêt immédiat en cas de danger.** `[A]`
