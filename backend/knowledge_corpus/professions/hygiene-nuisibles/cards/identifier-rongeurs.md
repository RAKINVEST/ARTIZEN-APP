## Cadrage
- **Objectif** : reconnaître une infestation de **rongeurs** (rats, souris) à leurs indices et évaluer les risques sanitaires. `[C]`
- **Résumé** : identifier les **indices** de rongeurs : **crottes**, **rongements** (câbles, denrées), traces de passage/graisse, bruits nocturnes, nids, odeur ; distinguer **rat** et **souris** (taille/comportement), repérer les **points d'entrée** (réseaux, gaines, toiture) et les sources de nourriture ; évaluer les **risques** (leptospirose, incendie par rongement, souillure des denrées) — l'identification oriente la prévention (exclusion) et le traitement (présentation). `[C]` ⟦espèces/indices selon contexte à confirmer⟧

## Réalisation
- **Étapes** *(compréhension / diagnostic / organisation — aucun protocole de dératisation, désinsectisation ou désinfection décrit)* :
  1. Repérer **crottes / rongements / passages**. `[C]` → [traces-rongeurs-infestation](../../../diagnostics/hygiene-nuisibles/traces-rongeurs-infestation.md)
  2. Distinguer **rat / souris** ; localiser nids/nourriture. `[C]`
  3. Repérer les **points d'entrée** (réseaux/toiture). `[C]` → [prevenir-hygiene-lutte-integree](prevenir-hygiene-lutte-integree.md)
  4. Évaluer les **risques sanitaires** (leptospirose, câbles). `[A]`
- **Points critiques** : espèce/ampleur identifiées ; points d'entrée localisés ; **risques sanitaires** évalués ; base de la prévention.
- **Sécurité** : zoonoses (rongeurs) ; morsures ; — **Produits biocides** (rodenticides, insecticides, désinfectants) : **dangereux** (toxiques pour l'humain, les animaux non-cibles, l'environnement) — leur **application professionnelle** est **réglementée** (**Certibiocide**, Règlement Biocides, AMM), sous EPI et **protection des occupants** ; **ce Livre ne décrit aucun protocole, dosage ni mode d'application** (présentation uniquement). **Risques sanitaires** : les nuisibles transmettent des **maladies** (leptospirose des rongeurs, allergies/asthme liés aux blattes, piqûres) et souillent les denrées → hygiène. **Guêpes / frelons** : piqûres (**choc anaphylactique**), nids en hauteur → intervention spécialisée. **Protection des occupants et animaux** ; aération ; appâts **sécurisés** (boîtes verrouillées). **Amiante** (locaux anciens, combles) : diagnostic ; retrait réservé à une **entreprise certifiée** (**jamais ici**). **Arrêt immédiat en cas de danger.** `[A]`

## Cadre & suites
- **Normes** : accès des nuisibles par les réseaux (siphons / clapets anti-rongeurs, **interface** plomberie) **DTU 60.1** ; **ventilation** contre l'humidité favorisant les nuisibles (**interface**) **DTU 68.3** ; services de lutte antiparasitaire **NF EN 16636** (certification CEPA), **Règlement Sanitaire Départemental**, **Règlement Biocides UE 528/2012 / Certibiocide** et **HACCP** (locaux alimentaires) ⟦en prose, à confirmer⟧ `[B]` ⟦références/versions exactes à confirmer par le validateur⟧. `respecte-norme`
