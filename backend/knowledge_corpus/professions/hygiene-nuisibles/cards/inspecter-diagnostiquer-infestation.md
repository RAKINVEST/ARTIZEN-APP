## Cadrage
- **Objectif** : organiser l'**inspection** d'un site et le **diagnostic** d'infestation (espèce, ampleur, points d'entrée). `[C]`
- **Résumé** : réaliser une **inspection méthodique** (locaux, réserves, gaines, réseaux, combles, abords), poser des **pièges de détection/monitoring**, identifier l'**espèce**, estimer l'**ampleur** et les **points d'entrée**/sources de nourriture, puis décider d'une **stratégie de lutte intégrée** (hygiène, exclusion, surveillance, traitement présenté) ; consigner les constats. `[C]` ⟦méthode d'inspection selon site à confirmer⟧

## Réalisation
- **Étapes** *(compréhension / diagnostic / organisation — aucun protocole de dératisation, désinsectisation ou désinfection décrit)* :
  1. **Inspecter** locaux/réseaux/abords ; pièges de monitoring. `[C]`
  2. Identifier **espèce / ampleur / points d'entrée**. `[C]` → [identifier-rongeurs](identifier-rongeurs.md)
  3. Décider une **stratégie de lutte intégrée**. `[C]` → [prevenir-hygiene-lutte-integree](prevenir-hygiene-lutte-integree.md)
  4. **Consigner** (gestion documentaire). `[C]` → [controle-hygiene-surveillance-nuisibles](../../../checklists/hygiene-nuisibles/controle-hygiene-surveillance-nuisibles.md)
- **Points critiques** : espèce/ampleur diagnostiquées ; points d'entrée localisés ; stratégie intégrée ; constats consignés.
- **Sécurité** : biocides (si traitement) ; zoonoses ; hauteur (combles). **Produits biocides** (rodenticides, insecticides, désinfectants) : **dangereux** (toxiques pour l'humain, les animaux non-cibles, l'environnement) — leur **application professionnelle** est **réglementée** (**Certibiocide**, Règlement Biocides, AMM), sous EPI et **protection des occupants** ; **ce Livre ne décrit aucun protocole, dosage ni mode d'application** (présentation uniquement). **Risques sanitaires** : les nuisibles transmettent des **maladies** (leptospirose des rongeurs, allergies/asthme liés aux blattes, piqûres) et souillent les denrées → hygiène. **Guêpes / frelons** : piqûres (**choc anaphylactique**), nids en hauteur → intervention spécialisée. **Protection des occupants et animaux** ; aération ; appâts **sécurisés** (boîtes verrouillées). **Amiante** (locaux anciens, combles) : diagnostic ; retrait réservé à une **entreprise certifiée** (**jamais ici**). **Arrêt immédiat en cas de danger.** `[A]`

## Cadre & suites
- **Normes** : accès des nuisibles par les réseaux (siphons / clapets anti-rongeurs, **interface** plomberie) **DTU 60.1** ; **ventilation** contre l'humidité favorisant les nuisibles (**interface**) **DTU 68.3** ; services de lutte antiparasitaire **NF EN 16636** (certification CEPA), **Règlement Sanitaire Départemental**, **Règlement Biocides UE 528/2012 / Certibiocide** et **HACCP** (locaux alimentaires) ⟦en prose, à confirmer⟧ `[B]` ⟦références/versions exactes à confirmer par le validateur⟧. `respecte-norme`
