# Constitution

> **Version** 1.0 — **Status** Frozen — **Owner** Architecture — **Last Update** 2026-08-02

## Objective
Contenir les **lois inviolables** (Bible Produit, Vol. 10). Toute idée qui viole une loi est rejetée. La cohérence prime sur la quantité de fonctionnalités.

## Contains
Les 20 lois fondamentales et l'ordre de priorité en cas de conflit : Législation → Entreprise → Utilisateur → Statistiques.

## Navigation
**Pourquoi :** garde-fou de toute décision. **Public :** décideurs, dev, IA. **Avant :** [manifesto/](../manifesto/README.md). **Après :** [architecture/](../architecture/README.md). **Dépendants :** architecture, domain, engines, contracts, ADR.

## Rules
Chaque ADR et chaque règle métier cite la ou les lois qu'elle respecte.

## Forbidden
Modifier une loi hors décision explicite du Product Owner.

## Acceptance Criteria
Les 20 lois présentes, numérotées, référençables par identifiant.
