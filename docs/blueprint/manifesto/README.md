## Objective
Dire **pourquoi** Artizen existe et quelle promesse il tient. Le plus stable après la Constitution : il fixe l'intention, pas les moyens.

## Contains
Promesse produit, étoile polaire, ce qu'Artizen est (mémoire, compagnon, moteur métier) et n'est pas (un simple logiciel de devis).

## Navigation
**Pourquoi :** ancrer toute décision dans l'intention. **Public :** tous. **Avant :** [README](../README.md). **Après :** [constitution/](../constitution/README.md). **Dépendants :** l'ensemble du Blueprint.

## Rules
Aucune fonctionnalité ne se justifie si elle ne sert pas la promesse.

## Acceptance Criteria
Lisible en 5 minutes, aucun terme d'ingénierie.
