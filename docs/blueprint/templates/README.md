## Objective
Fournir les **modèles officiels**. Tout nouveau document part d'un template pour garantir l'homogénéité et la navigation.

## Navigation
**Pourquoi :** un seul format partout. **Public :** contributeurs. **Avant :** [quality/](../quality/README.md). **Après :** [adr/](../adr/README.md). **Dépendants :** tous les documents.

## Rules
Ne jamais rédiger un document hors template. Copier, renommer, remplir tous les champs.

## Acceptance Criteria
Un template existe pour chaque type de document cité par la mission.
