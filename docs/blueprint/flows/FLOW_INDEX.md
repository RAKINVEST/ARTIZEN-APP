## Objective
Accès rapide aux flux, par parcours métier de l'artisan (du prospect à l'archivage).

## Parcours de référence
1. **Démarrer** : Créer une entreprise → un utilisateur → inviter un collaborateur.
2. **Le client** : Créer un client → un chantier.
3. **Le travail** : Créer une mission → une intervention → planifier → (reporter) → clôturer.
4. **Le commerce** : Créer/importer/extraire/modifier un devis → envoyer → signer → transformer en mission.
5. **L'argent** : Créer une facture → encaisser → (avoir) ; bon de commande → commander → réceptionner.
6. **La bibliothèque** : kit / phrase (créer, réutiliser).
7. **Les preuves** : ajouter une photo / créer un document / partager.
8. **Le suivi** : garantie · maintenance · rapport · notification · workflow · audit.
9. **Le cycle de vie** : archiver · restaurer · supprimer.
