## Objective
Fixer les **principes d'interface** : langage artisan, mode silencieux, complexité cachée (Loi 15).

## Contains
Vocabulaire autorisé / interdit à l'écran (deux langues), règles : pas de pop-up bloquante, le logiciel propose, l'artisan décide.

## Navigation
**Pourquoi :** l'utilisateur ne subit jamais la complexité. **Public :** design, Flutter. **Avant :** [product/](../product/README.md). **Après :** [quality/](../quality/README.md). **Dépendants :** —.

## Rules
Le logiciel propose, l'artisan décide. Rien de bloquant, rien d'envahissant.

## Forbidden
Vocabulaire informatique à l'écran (erreur, objet, provider, synchronisation…).

## Acceptance Criteria
Tout écran passe le test des 5 secondes et n'affiche aucun terme d'ingénierie.
