- **Terminé** : parcours complet Client → Dossier → Articles → Personnaliser →
  Récap → Créer → Terminé (P4.1 → P4.7).
- **Certifié** : aucune anomalie bloquante, validé en HTTP réel contre le backend.
  Voir [`10_V1_WIZARD_RELEASE.md`](10_V1_WIZARD_RELEASE.md) et

**Cette base est considérée comme acquise et ne doit pas être remise en cause
par les chantiers V1.1.**

## V1.1 — Backlog (chantiers indépendants)

### Chantier 1 (officiel, prioritaire) — Intégration du Copilote IA au Wizard

Ce **n'est pas** une tâche de nettoyage / reroutage : c'est une **évolution
fonctionnelle**. Aujourd'hui : `IA → quoteDraftLinesProvider → QuoteFormScreen`.
Cible : `IA → QuoteDraft → Wizard (étape Personnaliser) → Récap → Création`.

Périmètre pressenti :
- injection des suggestions IA dans `QuoteDraft` (mapping suggestions → `DraftLine`) ;
- pré-ouverture du Wizard **à la bonne étape** (client déjà choisi ? lignes déjà là) ;
- **conservation du parcours manuel** existant (le Wizard sans IA reste identique) ;
- tests dédiés à ce nouveau parcours (IA → Wizard → devis) ;
- **à l'issue** : retrait de `QuoteFormScreen` + de la route `/quotes/new` (dernier
  appelant supprimé — cf. [quote_assistant_screen.dart:155]).
